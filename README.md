# Site — Alumimais Vidraçaria 🪟

Site institucional da **Alumimais Comércio de Vidros e Esquadria Ltda** (CNPJ 48.205.057/0001-53) — vidraçaria cliente da Alfa Grupo Contábil, em Jaboticabal/SP.

## O que tem

- **One-page responsiva** (HTML + CSS + JS puros, sem dependências)
- Hero com chamada para WhatsApp
- 6 serviços: boxes, guarda-corpos, esquadrias, espelhos, fachadas, divisórias
- Seção sobre + estatísticas · Processo em 4 passos
- Galeria com lightbox · Depoimentos
- Formulário que abre o WhatsApp com a mensagem pronta
- Botão flutuante de WhatsApp · SEO local (meta tags)

## Como rodar

```bash
npm install
npm run dev      # desenvolvimento
npm run build    # produção (pasta dist/)
```

> **Nota:** basta abrir o `index.html` no navegador — não precisa de build.
